# 강의자료 (lectures/)

주차별 강의자료. 설계 근거는 [`docs/lecture-outlines.md`](../docs/lecture-outlines.md), 집필 규정은 [`docs/style-guide.md`](../docs/style-guide.md).

## 주차 폴더 표준 (2026-08-28, 전반부 확정)

**강의노트가 자료의 중심이다.** 영문 노트가 원본이고 국문 노트는 그 번역이며, 슬라이드는 노트의 단순 요약이다. 각 교수 주차 폴더는 다음 다섯 파일로 구성된다.

| 파일 | 역할 |
|---|---|
| `notes.en.md` | 강의노트 원본(영문, source of truth) — 내용 수정은 여기서 시작 |
| `notes.md` | 강의노트 국문 번역 — 영문 수정 후 동기화 |
| `slides.en.qmd` | 슬라이드(영문) — 노트 절 단위 요약, Quarto revealjs |
| `slides.ko.qmd` | 슬라이드(국문) — 영문 덱의 번역 |
| `WN_lab_*.ipynb` | 실습 노트북 (설계 기준: [`labs/README.md`](../labs/README.md)) |
| `WN_lab_*.ko.ipynb` | 실습 노트북 국문판(선택) — 마크다운 셀만 번역, 코드 셀은 영문판과 동일 유지 |
| `WN_hw_*.ipynb` | 과제 노트북(해당 주만) — 실습과 같은 표준, 다음 주 수업 전 제출. 현재 W3(차트 reflection) |

슬라이드 규칙: `theme: white` + `scrollable: true` 고정 — 화면 맞춤·레이아웃을 신경 쓰지 않는다. 절당 `##` 슬라이드 하나, 불릿과 단순 표만 사용, mermaid·컬럼·커스텀 색 금지. 렌더링과 게시는 `site/build.sh`가 일괄 수행한다(생성물은 `site/_site/`로만 나가고 이 폴더에는 남지 않는다).
