# 갈래 ① — 추론할 때 계산을 더 쓴다

---

# Self-Consistency — 여러 번 생각하고 다수결

**Self-Consistency** = 같은 질문을 여러 번 샘플링해 나온 **최종 답들의 다수결**을 취하는 기법 (Wang et al., 2022).

```
             ┌→ 경로 A … 답 X
질문 (온도>0)─┼→ 경로 B … 답 Y   →  다수결 → X
             └→ 경로 C … 답 X
```

**왜 되는가:** 정답으로 가는 길은 여러 갈래지만 **도착지는 하나**다. 오답은 제각각 다른 곳에 흩어진다. 그래서 투표하면 정답에 표가 모이고 오답은 갈린다.

학습을 하나도 안 바꾸고, **추론 시점에 계산을 더 써서** 정확도를 산다.

<p class="small">지난주 교수 시연이 바로 이 논문 — "기억나죠?" 로 연결. 향상 폭 수치는 그 시연/발표에서 확인</p>

<!--

-->

# 일반화 — test-time compute

**test-time compute** = 학습(가중치)은 그대로 두고, **추론 시점에 계산을 더 써서** 성능을 올리는 접근. self-consistency는 그 한 예일 뿐 — 방법군 전체는:

| 방법 | 계산을 더 쓰는 방식 |
|---|---|
| Self-consistency | 병렬로 N번 → 다수결 |
| Best-of-N | N번 생성 → 채점기가 최고 선택 |
| 더 긴 사고 | 한 경로를 깊게 (오늘 뒤의 o1·R1) |
| 트리 탐색 | 분기·평가·백트래킹 (→ W5) |

**공통 원리:** 학습은 그대로, **추론에서 계산 ↑ = 정확도 ↑.**

**단, 공짜가 아니다** — N번 = 비용·지연 N배. 그래서 실무 질문은 "N을 몇으로?"가 아니라 **"어떤 질문에만 N>1을?"**(→ W8 적응형).

# 질문을 뒤집자

매번 21번 물을 수는 없다. 그런데—

> 다수결로 **정답을 골라낼 수 있다**는 건,
> 정답으로 가는 **좋은 풀이를 골라낼 수 있다**는 뜻 아닌가?

골라낸 좋은 풀이로 **모델을 다시 학습**시키면?
→ 추론 시점의 계산이 **모델 가중치 속으로** 들어간다.

이 아이디어를 2022년에 실행한 게 **STaR**, 2025년에 끝까지 민 게 **DeepSeek-R1**이다.

# STaR — 스스로 만든 풀이로 스스로 배운다

**STaR (Self-Taught Reasoner)** = 모델이 스스로 만든 풀이 중 **정답을 맞힌 것만 걸러 재학습**하는 부트스트랩 방법 (Zelikman et al., 2022).

```
① 풀이 생성: 문제마다 CoT로 풀게 한다
② 필터:     최종 답이 맞은 풀이만 남긴다
③ 재학습:   남은 풀이로 모델을 파인튜닝
④ 반복:     더 똑똑해진 모델로 ①부터 다시
```

- 사람이 풀이를 **한 줄도 안 써준다** — 예시 몇 개만 시드로
- 핵심 트릭: 풀이의 품질은 못 재도 **답의 정오는 잴 수 있다** ← 이 정오가 필터
- 지난주 배운 **자기 생성 + 유용성 필터** 패턴 — 이게 도구(W4)에서 또 나온다

<p class="small">작은 모델이 훨씬 큰 모델을 따라잡은 수치는 오늘 발표 ①(STaR)에서 확인</p>

# 잠깐 — 강화학습(RL) 3분, 개념만

다음 논문(R1)을 읽는 데 필요한 건 수식이 아니라 **개념 하나**다.

**강아지에게 "앉아"를 가르친다면:** 정답 동작을 *보여줄* 방법이 없다. 대신 우연히 앉으면 → 간식. 간식 받은 행동이 점점 자주 나온다. 끝.

| | 지도학습 (SFT) | 강화학습 (RL) |
|---|---|---|
| 주는 것 | **정답 시연** ("이렇게 해") | **점수만** ("잘했어/못했어") |
| 배우는 것 | 시연을 흉내 | 점수 받는 행동을 늘리기 |
| 한계·잠재력 | 시연자보다 못함 | 시연 없이 **시연자를 넘을 수도** |

> 오늘 필요한 전부: **점수를 주면, 점수 받는 행동이 늘어난다.** (가중치를 어떻게 바꾸는지는 이 과목 밖)

# DeepSeek-R1 — 순수 RL로 추론이 창발한다

STaR의 필터("답 맞으면 남긴다")는 사실상 **보상**이다. 그럼 제대로 된 RL로, 큰 모델에서, 끝까지 돌리면?

**R1-Zero의 레시피 — 충격적으로 단순하다:**
- 베이스 모델에서 시작, **사람의 풀이 시연 0개**
- 보상은 규칙 둘뿐: **정답이면 +**, **형식 지키면 +**
- RL을 오래 돌린다

**그랬더니 아무도 가르치지 않은 행동이 스스로 나타났다** — 생각이 점점 길어지고, 검산·대안 탐색·**자기 교정**이 창발했다. 훈련 중 모델이 스스로 *"Wait, wait. 다시 보자"* 를 말한다.

<p class="small">AIME 창발 곡선·"aha moment" 원문은 오늘 발표 ②(R1)에서 수치·인용으로 확인</p>

<!--

# 두 갈래가 만나는 곳 — 보상 설계가 곧 사양서

R1-Zero의 생각은 **읽기 어렵고 언어가 섞였다** — 보상에 '가독성'이 없었으니까. R1은 소량의 좋은 예시로 다듬은 뒤(SFT) 다시 RL로 마감했다.

교훈 두 줄, 학기 내내 이어진다:
- **능력은 RL이 만들고, 태도는 SFT가 다듬는다**
- **보상에 넣지 않은 것은 얻지 못한다** — 보상 설계가 곧 사양서 (→ W13 평가)

그리고 R1도 마지막엔 **다수결(갈래 ①)** 을 얹어 더 오른다 — **두 갈래는 곱해진다.**

<!--

# 내 루프에 어떤 모델을 넣을까

추론 모델은 "생각을 얼마나 할지"를 **파라미터로 조절**한다 — 벤더마다 이름은 달라도 개념은 하나: **thinking budget(생각 예산).**

판단의 감각:

| | 일반 모델 | 추론 모델 |
|---|---|---|
| 강점 | 도구 호출·정형 작업 | 수학·계획·까다로운 판단 |
| 루프 설계 | 여러 바퀴 돌며 보정 | 적은 바퀴, 한 수를 깊게 |

- **기본값은 싼 모델** — 추론 모델은 병목 *지점*에만
- "바꿨더니 좋아진 *느낌*" 금지 — **측정이 근거**다 (→ W13)

# 발표에서 확인하고 · 실습에서 만든다

**발표 ① STaR** — 스스로 만든 풀이로 부트스트랩하는 아이디어와, 작은 모델이 큰 모델을 따라잡는 수치.
**발표 ② DeepSeek-R1** — 순수 RL로 추론이 창발하는 곡선과 'aha moment'.

**오후 실습:** 갈래 ①을 직접 만든다 — 같은 질문을 N번 샘플링해 **다수결**(self-consistency). N=1과 N=5의 정확도를, **비용까지 재서** 비교한다("5배 낼 값이 있었나"까지가 실습).

# 오늘 남길 세 문장

1. **Test-time compute** — 학습은 그대로, 추론에서 계산을 더 써서 정확도를 산다(다수결: 정답은 모이고 오답은 흩어진다)
2. **STaR** — 답의 정오로 좋은 풀이를 걸러 재학습 = 스스로 가르치기
3. **R1** — 그 필터를 제대로 된 RL로: 정답 보상만으로 긴 사고·자기교정이 **창발**한다

**다음 주 (W4. 도구 사용):**
지금까지 모델은 *생각*만 잘한다 — 계산기 하나 못 쓴다. **말을 행동으로 바꾸는 연결**을 개념부터 뜯고, 도구를 직접 붙인다.
