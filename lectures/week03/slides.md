# 갈래 ① · 추론 시점의 계산 확대

# Self-Consistency — 다중 샘플 다수결

**Self-Consistency** = 같은 질문을 여러 번 샘플링해 나온 **최종 답들의 다수결**을 취하는 기법 (Wang et al., 2022).

우리가 알고 싶은 건 답 $a$의 확률인데, 답은 중간 추론 경로 $r$를 거쳐 나온다. 그래서 특정 경로 하나가 아니라 **모든 경로를 합쳐야** 답의 진짜 확률이 된다:

$$P(a \mid q) \;=\; \sum_{r} P(a \mid r, q)\,P(r \mid q)$$

- **한 번만 물으면**: 확률이 가장 높은 경로 하나가 내놓은 답만 본다 → 그 경로가 틀리면 그대로 오답
- **여러 번 샘플해 다수결**: 위 합을 **샘플로 근사**한 것 — 서로 다른 경로가 같은 답에 모이면 그 답이 이긴다

**왜 이득인가:** 정답은 여러 경로가 같은 곳으로 수렴하지만, 오답은 경로마다 제각각이라 표가 흩어진다. 그래서 합산(=다수결)이 정답을 위로 띄운다.

<p class="small">지난주 교수 시연이 바로 이 논문 — 향상 폭 수치는 그 시연·발표에서 확인</p>

# 일반화 — test-time compute

**test-time compute** = 학습(가중치)은 그대로 두고, **추론 시점에 계산을 더 써서** 성능을 올리는 접근. self-consistency는 그 한 예일 뿐 — 방법군 전체는:

| 방법 | 계산을 더 쓰는 방식 |
|---|---|
| Self-consistency | 병렬로 N번 → 다수결 |
| Best-of-N | N번 생성 → **검증기(verifier)** 가 최고 선택 |
| 더 긴 사고 | 한 경로를 깊게 (오늘 뒤의 o1·R1) |
| 트리 탐색 | 분기·평가·백트래킹 (→ W5) |

**공통 원리:** 학습은 그대로, 추론에서 계산 ↑ = 정확도 ↑ — 이를 **추론 시점 스케일링(inference-time scaling)** 이라 하며 o1·R1의 근간이다. (다수결과 달리 Best-of-N·트리 탐색은 답을 고를 검증기/보상 모델을 요구한다.)

**단, 공짜가 아니다** — N번 = 비용·지연 N배. 그래서 실무 질문은 "N을 몇으로?"가 아니라 **"어떤 질문에만 N>1을?"**(→ W8 적응형).

# 선별에서 학습으로의 전환

매번 21번 물을 수는 없다. 그런데—

> 다수결로 **정답을 골라낼 수 있다**는 건,
> 정답으로 가는 **좋은 풀이를 골라낼 수 있다**는 뜻 아닌가?

골라낸 좋은 풀이로 **모델을 다시 학습**시키면?
→ 추론 시점의 계산이 **모델 가중치 속으로** 들어간다.

이 아이디어를 2022년에 실행한 게 **STaR**, 2025년에 끝까지 민 게 **DeepSeek-R1**이다.

# STaR — 자기 생성 풀이 부트스트랩

**STaR (Self-Taught Reasoner)** = 모델이 스스로 만든 풀이 중 **정답을 맞힌 것만 걸러 재학습**하는 부트스트랩 방법 (Zelikman et al., 2022).

```
① 풀이 생성: 문제마다 CoT로 풀게 한다
② 필터:     최종 답이 맞은 풀이만 남긴다
③ 재학습:   남은 풀이로 모델을 파인튜닝
④ 반복:     더 똑똑해진 모델로 ①부터 다시
```

- 사람이 풀이를 **한 줄도 안 써준다** — 예시 몇 개만 시드로
- 핵심 트릭: 풀이의 품질은 못 재도 **답의 정오는 잴 수 있다** ← 이 정오가 필터
- 형식적으로는 **기댓값 최대화(EM)** 의 근사 — 맞는 풀이(잠재변수)를 추정하고(E), 그 풀이로 모델을 갱신(M)한다
- 지난주 배운 **자기 생성 + 유용성 필터** 패턴 — 도구(W4)에서 또 나온다

<p class="small">작은 모델이 훨씬 큰 모델을 따라잡은 수치는 오늘 발표 ①(STaR)에서 확인</p>

# 강화학습(RL) — 정의와 직관

**강화학습(RL)** = 정답을 시연하지 않고 **보상(점수)만으로** 정책을 개선하는 학습. 학습 대상인 행동 규칙을 **정책(policy)** 이라 하고, LLM에서는 **모델 자체가 정책**이다.

비유 — 강아지: 정답 동작을 보여줄 수 없으니, 우연히 앉으면 간식을 준다. 간식 받은 행동이 잦아진다.

| | 지도학습 (SFT) | 강화학습 (RL) |
|---|---|---|
| 주는 신호 | **정답 시연** | **보상(점수)** |
| 배우는 것 | 시연을 흉내 | 보상을 높이는 행동 |
| 한계·잠재력 | 시연자를 넘지 못함 | 시연 없이 **시연자를 넘을 수도** |

# LLM에서의 RL — RLHF와 RLVR

LLM에 대응시키면: **행동** = 답안 하나를 생성 · **보상** = 그 답안의 점수 · **학습** = 보상을 높이는 방향으로 정책(모델)을 갱신.

보상을 **누가 매기느냐**로 두 갈래 — 이 구분이 R1을 이해하는 열쇠다:

- **RLHF** (Reinforcement Learning from Human Feedback) — 사람 선호로 학습한 **보상 모델**이 채점. ChatGPT 정렬의 방법.
- **RLVR** (RL with Verifiable Rewards) — **규칙으로 검증 가능한 보상**: 정답 일치·테스트 통과·형식 준수. 학습된 보상 모델이 없어 **조작(해킹)이 어렵다.** → 오늘의 R1.

> 정책을 실제로 갱신하는 알고리즘(PPO·GRPO 등)은 이 과목 밖 — 발표의 선택 심화로.

# DeepSeek-R1 — 순수 RL과 추론 창발

**DeepSeek-R1** = 사람의 풀이 시연 없이 **순수 RL만으로 추론 능력을 학습**시킨 공개 모델 (2025).

논리 연결: STaR의 필터("답 맞으면 남긴다")는 사실상 **보상**이다 — 그럼 제대로 된 RL로, 큰 모델에서, 끝까지 돌리면?

**R1-Zero의 레시피 (RLVR의 극단):**
- 베이스 모델에서 **바로 RL** — SFT 콜드스타트도, 사람 시연도 0
- 보상은 **규칙 기반 둘뿐**(정답 일치 + 형식) — 학습된 보상 모델이 없어 **보상 해킹 표면이 좁다**
- 정책은 한 문제에 **여러 답을 뽑아, 그 그룹 안에서 상대적으로 나은 답을 강화**하는 식으로 갱신한다(GRPO; 잘잘못을 따로 매기는 가치함수 없이) — 상세는 발표로

**그랬더니 아무도 가르치지 않은 행동이 스스로 나타났다** — 생각이 점점 길어지고, 검산·대안 탐색·**자기 교정**이 창발했다. 훈련 중 모델이 스스로 *"Wait, wait. 다시 보자"* 를 말한다.

<p class="small">AIME 창발 곡선·"aha moment" 원문은 오늘 발표 ②(R1)에서 수치·인용으로 확인</p>

# 보상 설계 = 사양서 (두 접근의 결합)

R1-Zero의 생각은 **읽기 어렵고 언어가 섞였다** — 보상에 '가독성'이 없었으니까. R1은 소량의 좋은 예시로 다듬은 뒤(SFT) 다시 RL로 마감했다.

교훈 두 줄, 학기 내내 이어진다:
- **능력은 RL이 만들고, 태도는 SFT가 다듬는다**
- **보상에 넣지 않은 것은 얻지 못한다** — 보상 설계가 곧 사양서. 이것이 **보상 해킹(reward hacking)** 의 씨앗이다: 지표를 최적화하면 지표가 목표를 대변하기를 멈춘다(**Goodhart의 법칙**). W13에서 정면으로 다룬다

그리고 R1도 마지막엔 **다수결(갈래 ①)** 을 얹어 더 오른다 — **두 갈래는 곱해진다.**

# 모델 선택 — 일반 모델 vs 추론 모델

추론 모델은 "생각을 얼마나 할지"를 **파라미터로 조절**한다 — 벤더마다 이름은 달라도 개념은 하나: **thinking budget(생각 예산).**

판단의 감각:

| | 일반 모델 | 추론 모델 |
|---|---|---|
| 강점 | 도구 호출·정형 작업 | 수학·계획·까다로운 판단 |
| 루프 설계 | 여러 바퀴 돌며 보정 | 적은 바퀴, 한 수를 깊게 |

- **기본값은 싼 모델** — 추론 모델은 병목 *지점*에만
- "바꿨더니 좋아진 *느낌*" 금지 — **측정이 근거**다 (→ W13)

# 오늘의 연결 — 발표와 실습

**발표 ① STaR** — 스스로 만든 풀이로 부트스트랩하는 아이디어와, 작은 모델이 큰 모델을 따라잡는 수치.
**발표 ② DeepSeek-R1** — 순수 RL로 추론이 창발하는 곡선과 'aha moment'.

**오후 실습:** 갈래 ①을 직접 만든다 — 같은 질문을 N번 샘플링해 **다수결**(self-consistency). N=1과 N=5의 정확도를 **비용과 함께** 비교한다 — 계산을 더 쓴 만큼 값어치를 했는지까지가 실습이다.

# 요약

1. **Test-time compute** — 학습은 그대로, 추론에서 계산을 더 써서 정확도를 산다(다수결: 정답은 모이고 오답은 흩어진다)
2. **STaR** — 답의 정오로 좋은 풀이를 걸러 재학습 = 스스로 가르치기
3. **R1** — 그 필터를 제대로 된 RL로: 정답 보상만으로 긴 사고·자기교정이 **창발**한다

**다음 주 (W4. 도구 사용):**
지금까지 모델은 *생각*만 잘한다 — 계산기 하나 못 쓴다. **말을 행동으로 바꾸는 연결**을 개념부터 뜯고, 도구를 직접 붙인다.
