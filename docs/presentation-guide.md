# 논문 발표 가이드

> 발표의 목표는 **"논문 요약"이 아니라 "이해했음을 증명"**이다.
> 슬라이드 낭독 금지 · 본인 언어로 재구성 · 교수의 콜드 질문에 답할 수 있어야 한다.

## 1. 3시간 수업 시간 배분

| 블록 | 시간 |
|---|---|
| 이론 강의 (교수) | 40분 |
| **논문 발표 2편** (편당 20분) | 40분 |
| 휴식 | 10분 |
| from-scratch 실습 | 80분 |
| 마무리·다음주 예고 | 10분 |
| **합계** | **180분** |

## 2. 발표 1편 = 20분 (고정)

| 단계 | 시간 | 내용 |
|---|---|---|
| 발표 | **12분** | 슬라이드 6장 상한, **하드 스톱**(타이머 표시) |
| 이해 검증 Q&A | **6분** | 교수 콜드 질문 + 지정 토론자 |
| 전환·정리 | 2분 | 다음 발표 준비 |

**시간 제한 강제:** 12분에서 강제 종료. 슬라이드 6장 초과 금지. 시간 초과·슬라이드 초과는 감점.
적게 강제해야 압축되고, 압축은 이해를 요구한다.

## 3. 발표 템플릿 (슬라이드 6장 · 4항목 루브릭과 1:1 매핑)

| # | 슬라이드 | 시간 | 루브릭 |
|---|---|---|---|
| 1 | **한 문장 기여** — "이 논문은 [문제]를 [핵심 아이디어]로 푼다" | 1분 | 핵심 기여 |
| 2 | **문제·동기** — 왜 지금, 기존의 한계 | 2분 | 핵심 기여 |
| 3 | **핵심 메커니즘** — ⚠️ 본인이 직접 그린 그림 1장 (논문 그림 복붙 금지) | 4분 | 방법 이해 |
| 4 | **핵심 결과 1개** — 가장 중요한 실험 하나가 무엇을 증명하나 | 2분 | 방법 이해 |
| 5 | **가장 약한 가정·한계** — 본인이 짚는 비판 | 2분 | 비판적 분석 |
| 6 | **연결** — 후속 논문 또는 본인/연구실 주제 | 1분 | 연결·확장 |

> 심화(🔴) 논문은 수식 유도 생략 가능 — 직관 수준의 메커니즘 설명이면 충분하다.

## 4. 이해 검증 — 교수 콜드 질문 3종

발표 후, **슬라이드를 끄고** 화이트보드에서 답한다. 교수가 무작위로 1~2개 선택.

1. **메커니즘 / ablation** — "이 방법에서 [X 단계]를 빼면 어떻게 되나?"
2. **재현** — "처음부터 구현한다면 첫 3단계는?" *(← 그 주 from-scratch 실습과 직결)*
3. **경계 / 실패** — "이 방법이 실패하는 입력·상황을 하나 만들어봐라"

암기한 학생은 슬라이드 없이는 답하지 못하고, 이해한 학생은 답한다. 이것이 둘을 가른다.
각 주차 README의 **토론 포인트**가 교수용 추가 백업 질문이다.

## 5. 지정 토론자 (Discussant)

- 매 발표마다 학생 **1명을 사전 배정** — 발표 후 **2분** 반박/보완 질문.
- 발표자와 토론자를 **둘 다 평가** → 청중도 논문을 읽어오게 되는 안전망.
- 토론자 질문 예: "5번 슬라이드의 한계, 실제로 그게 치명적인가?", "3번 메커니즘이 A 상황에서도 통하나?"

## 6. 평가 루브릭

| 항목 | 배점 | 기준 |
|---|---|---|
| 핵심 기여 | 30% | 논문의 기여를 한 문장으로 정확히 압축했는가 |
| 방법 이해 | 25% | 핵심 아이디어·메커니즘을 정확히 설명했는가 (심화는 직관 허용, 수식 생략 가능) · **콜드 질문 답변 반영** |
| 비판적 분석 | 25% | 가장 약한 가정·한계를 스스로 짚었는가 |
| 연결·확장 | 20% | 후속 논문 또는 본인/연구실 주제와 연결했는가 |

- **콜드 질문 답변**은 *방법 이해* + *비판적 분석*에 반영.
- **지정 토론자**는 질문의 날카로움으로 별도 소점수(참여 점수) 부여 권장.

## 7. 체크리스트

**발표자 (발표 전)**
- [ ] 슬라이드 6장 이하, 3번 메커니즘 그림을 내 손으로 그렸다
- [ ] 한 문장 기여를 말로 설명할 수 있다
- [ ] "이 방법을 처음부터 구현한다면?"에 답할 수 있다
- [ ] 가장 약한 가정 1개를 정했다

**청중·토론자**
- [ ] 논문을 읽고 질문 1개를 준비했다
- [ ] (지정 토론자) 반박/보완 포인트 2개를 준비했다
